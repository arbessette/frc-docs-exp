About FRC Documentation
=======================

FRC Documentation covers robot assembly, component hardware, wiring practices,
physical inspection, and competition preparation. Use official FIRST season
documents for competition requirements.

WPILib remains the home for software and control-system procedures. This
site links to those procedures and adapts hardware reference articles
with attribution.
