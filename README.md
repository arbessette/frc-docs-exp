# frc-docs

Welcome to frc-docs! This repository contains the source articles for the FRC
Documentation website, covering robot assembly, component hardware, wiring
practices, physical inspection, and competition preparation.

Documentation are credited in [About FRC Documentation](source/about.rst).

FRC Docs is part of [WPILib Suite](https://github.com/wpilibsuite), maintained in
[wpilibsuite/frc-docs](https://github.com/wpilibsuite/frc-docs).

# FRC Documentation Mission

Help FIRST Robotics Competition teams build, wire, inspect, and prepare their
robots using clear hardware guidance and manufacturer references. These
articles cover Systemcore robots; previous-controller procedures remain in the
legacy WPILib documentation. Unverified hardware details are marked explicitly.
Use official FIRST season documents for competition requirements.

Systemcore connections, software setup, programming, and development tools are
covered in [WPILib Docs](https://docs.wpilib.org/en/latest/). The two sites
connect assembly and hardware guidance to controller setup and the first drive.

# Contributing to frc-docs

Contributions can improve articles, diagrams, photographs, links, and navigation.
The [WPILib documentation contribution guide](https://docs.wpilib.org/en/latest/docs/contributing/wpilib-docs/index.html)
provides guidance on Sphinx and reStructuredText. Follow the
[WPILib Code of Conduct](https://github.com/wpilibsuite/allwpilib/blob/main/CODE_OF_CONDUCT.md).

For hardware instructions, include the manufacturer source and applicable
hardware revision, firmware, and season. Keep source credits with reused assets.
Edit `source/index.rst` for homepage navigation and `source/conf.py` for site settings.

For local builds, see the [WPILib documentation build instructions](https://docs.wpilib.org/en/latest/docs/contributing/wpilib-docs/build-instructions.html).
